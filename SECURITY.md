# Security Policy

## Supported Versions

We release security updates and bug fixes for actively maintained versions of MySCII Camera.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :x:                |
| < 1.1   | :x:                |

## Reporting a Vulnerability

The MySCII Camera team takes the security of our application and users seriously. If you believe you have discovered a vulnerability or security issue:

1. **Do not publicly disclose the issue** via GitHub issues, discussions, or social media.
2. Please report the issue via GitHub's [Private Vulnerability Reporting](https://github.com/aliyan212/MyScii-Camera/security/advisories/new) or directly contact the repository maintainers.
3. Include detailed steps to reproduce the issue, proof of concept, and impact assessment.

We will acknowledge receipt within 48 hours and coordinate a fix and release.
